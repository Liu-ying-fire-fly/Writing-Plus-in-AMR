# Writing_Plus

English | [中文](README.md)

An Automatic Modulation Recognition (AMR) paper-writing assistant that builds a
「vector index + knowledge graph」from a local paper library, implements a RAG
writing pipeline of 「vector recall → graph traversal expansion → cross-encoder
reranking → two-stage refinement」, and produces a paper draft with `[1][2]`
numbered citations.

## Pipeline

| Stage | Script | Purpose |
|-------|--------|---------|
| Indexing | `update_index.py` | Chunk + embed files under `markdown_data/`, incrementally build the FAISS index |
| Extraction | `02_relation_extraction.py` | LLM extracts entities / relations / performance results and records entity↔chunk provenance |
| Graph building | `03_graph_build.py` | Write into Neo4j (Paper / Entity / Chunk / PerformanceResult nodes + semantic edges) |
| Retrieval | `04_graph_retrieval.py` | Vector recall + graph traversal expansion (merged & deduplicated) |
| Generation | `05_refine_generate.py` | cross-encoder reranking + summarization + refinement generation |

`01_langchain_example.py` is an early example, and `print_content.py` prints vector chunk contents.

## Directory structure

```
.
├── 01_*.py / 02_*.py / ... / 05_*.py   # pipeline stages
├── update_index.py                     # vector indexing
├── embeddings.py                       # Qwen3 embedding wrapper
├── config.py / config.json             # unified config (dot-notation keys)
├── abbreviations.json                  # abbreviation → full-name table
├── markdown_data/                      # paper markdown (place here, see its README)
├── model/                              # embedding model weights (download, see its README)
└── paper_vertical/                     # FAISS index (generated by update_index.py)
```

## Install Docker (Linux)

### 1. Install Docker

Run the one-click install script:

```bash
sudo curl -fsSL https://github.com/tech-shrimp/docker_installer/releases/download/latest/linux.sh | bash -s docker --mirror Aliyun
```

Alternative install command:

```bash
sudo curl -fsSL https://gitee.com/tech-shrimp/docker_installer/releases/download/latest/linux.sh | bash -s docker --mirror Aliyun
```

### 2. Configure Docker registry mirrors

Edit the config file:

```bash
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://docker.m.daocloud.io",
                       "https://docker.1panel.live",
                       "https://hub.rat.dev"
                       ]
}
EOF
```

Then restart the Docker service:

```bash
sudo systemctl restart docker
```

## Quick start

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Prepare data and models:
   - Place paper `.md` files into `markdown_data/` (see `markdown_data/README.md`);
   - Download the embedding model into `model/` (see `model/README.md`).
3. Configure environment variables (secrets stay out of config files):
   ```bash
   export DEEPSEEK_API_KEY=...
   export NEO4J_URI=bolt://localhost:7687
   export NEO4J_USER=neo4j
   export NEO4J_PASSWORD=...
   ```
4. Start Neo4j (Docker, default `neo4j` database):
   ```bash
   docker run -d --name neo4j \
     -p 7474:7474 -p 7687:7687 \
     -e NEO4J_AUTH=neo4j/<YOUR_PASSWORD> \
     -v neo4j_data:/data \
     -v neo4j_logs:/logs \
     neo4j:5-community
   ```

   > `<YOUR_PASSWORD>` must match `NEO4J_PASSWORD` from the previous step.

   Then run the pipeline in order:
   ```bash
   python3 update_index.py
   python3 02_relation_extraction.py
   python3 03_graph_build.py --reset
   python3 04_graph_retrieval.py --query "what is AMR"
   python3 05_refine_generate.py --query "小样本识别的最好性能是哪篇论文？"
   ```

## Configuration

All tunable parameters live in `config.json` and are read via dot-notation keys in `config.py` (e.g. `chunking.chunk_size`, `embedding.model_path`).

> Note: changing `chunking` parameters alters chunking results, so you must re-run `update_index.py`, `02`, and `03` for a full rebuild.

## Security

API keys and database passwords are always passed via environment variables and never written into config files or code.
